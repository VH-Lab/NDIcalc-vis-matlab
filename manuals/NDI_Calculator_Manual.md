# NDI Calculator Manual

The canonical manual for writing `ndi.calculator` objects lives in the
[NDI-matlab](https://github.com/VH-Lab/NDI-matlab) repository.

Please refer to:

- [NDI_Calculator_Manual.md (main branch)](https://github.com/VH-Lab/NDI-matlab/blob/main/src/ndi/docs/NDI-matlab/manual/developer/NDI_Calculator_Manual.md)

It covers the repository structure, required components, a step-by-step
guide to creating a new calculator, optional methods, testing with mock
documents, and best practices.
